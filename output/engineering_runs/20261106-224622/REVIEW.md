# Codex CLI 그래프 전체 실행 기록

**실제 전체 실행 완료, 정식 비교·제출 완료 아님.** 기존 graph.py의 기획/병렬 배치/부족 절 재조사/점검/원고 보존/종합을 유지하고 Codex CLI를 선택형 어댑터로 연결했다. 실행 모델은 기존 ChatGPT 로그인 설정의 gpt-6.1-sol이다. 무료 OpenRouter 경로와 전역 설정을 바꾸지 않았다.

## 직접 대조 범위와 남은 내용

MESSENGER Press Kit/임무 소개, Venus Express ESA 브로슈어/우주선 소개의 실제 발췌와 최종 원고의 주요 수치·설계/성과·인과 표현을 대조했다. 태양광11배와 재복사열4배, 차양370°C/본체20°C/패널150°C, Venus Express의 Mars 대비 가열4배 및 전지 고온 내성120°C 등의 비교 기준을 구분했고, 명시된 사실과 관측 제약에 관한 추론을 표시했다. 주요 주장을 검토한 범위에서 원문 밖 수치를 발견하지 않았다.

내용은 미완료다. 관측 허용각도·최대 연속 관측시간 등 추가 정량값이 실제 질문을 답하는 데 필수인지와 부족 신고의 적정성은 별도 판단해야 한다. 중간표 한 행의 중국어 혼입, 최종 원고의 내부 출처ID D1/D2 표현도 남아 있다. 제출자의 직접 대조를 마친 것으로 표시하지 않는다.

- 위 실패/성공은 프롬프트·출력 정책이 달라 성능 비교나 개선 효과의 인과 실험으로 집계하지 않는다. 모든 폴더와 성공 호출 체크포인트를 보존했다.
- 현재 정책은 한 행 한 수치/실제 명사·대명사 선택을 지시하고, 실패 시 검증 오류만 전달하는 모델 재추출을 최대1회 허용한다. 이 성공 실행은 보정 분기가 발생하지 않았다. 보정 상한/재실패 중단은 오프라인 검사에서 확인했다. 프로그램이 틀린 사실표를 직접 고쳐 성공으로 만들지 않는다.

## 입력량과 예산

논리적 읽기 예산은 서로 다른 실제 열람4건이며, 모델 재추출이 있으면 같은 원문의 추가 입력도 context/CLI 호출 기록에 별도로 남긴다. 그래프의 prompt 글자 수는 명시적 업무 입력이고, 실제 CLI 사용량에는 Codex 공통 지시 등도 포함되므로 calls.json의 transport.usage와 함께 봐야 한다. 캐시는 같은 진단 안에서만 재사용한다. 모델/정책 identity가 달라지면 이전 호출 캐시 재개를 거부한다.

## 실행

```powershell
.venv/Scripts/python.exe -X utf8 run_planetary.py --live --engineering --transport codex --question-id P04 --sections 2 --budget 1 --rounds 1 --topic-cards
```

이 명령은 ChatGPT 구독 사용량으로 공개 자료·카드·사실표·원고를 Codex에 전송한다. API 키 환경변수 제거, read-only, 도구 비활성화, JSON Schema를 유지한다. 원본 pipeline.py는 변경하지 않았다. 현재 웹의 새 질문 실행 기본 경로는 여전히 OpenRouter이며, 이번 변경은 명시적 CLI 실행 선택이다. 웹에서 새 CLI 실행을 고르는 UI는 아직 없다. 자료실의 저장 진단 열람 경로는 같은 engineering_runs 형식이다.

## 컨텍스트 조건

현재 CLI 모델로는 기존 자료 전체가 기본 컨텍스트 안에 들어갔다. 별도 동일 세션 검사에서88건을 문서 단위3회에 나눠 넣었고 마지막 요청 입력344989토큰, 실행 당시 유효컨텍스트475000이었다. 관찰된 압축 이벤트는0이다. 누적765423토큰을 마지막 요청 크기로 오인하지 않았다. **따라서 이 모델·자료 조합은 과제의 서비스 컨텍스트 초과 조건 미충족**이다. 모델 자체 최대 한도와 고립된 본문 합계의 정확한 토큰 수를 입증한 것은 아니다. 이 결과 때문에 정식 비교는 시작하지 않았다.
